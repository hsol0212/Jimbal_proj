# Jimbal_CAM_STM32F411
Jimbal Project on STM32F411

🎥 3축 객체 추적 짐벌 시스템 (3-Axis Target Tracking Gimbal)

1. 프로젝트 소개

다중 MCU(ESP32, STM32) 환경에서 카메라 비전을 이용해 타겟을 실시간으로 추적하고, 모터 제어 및 화면 렌더링을 수행하는 3축 짐벌 시스템입니다. 통신 병목 현상과 메모리 부족 문제를 하드웨어 제어 기법을 통해 최적화하는 데 주력했습니다.

개발 기간: 2026.04.09 ~ 2026.05.11

담당 역할: 다중 MCU 간 통신 아키텍처 설계, 통신 병목 해결(DMA/핑퐁 버퍼), 시스템 메모리(RAM) 최적화

2. 사용 기술 (Tech Stack)

Language: C / C++

Hardware: STM32F411, ESP32, 3축 짐벌 모터, LCD 모듈

Protocol & Tech: SPI, UART, DMA (Direct Memory Access), Ping-Pong Buffer

3. 세부 수행 내용 및 트러블슈팅 (핵심 성과)

  1. DMA 및 핑퐁 버퍼를 활용한 렌더링 병목 해결

문제: 38KB의 무거운 영상 데이터를 수신해 LCD에 출력할 때 CPU가 대기 상태에 빠져 실시간 타겟 추적이 불가능한 렌더링 지연 현상 발생.

해결: 통신 방식을 고속 SPI로 변경하고, 하드웨어 통신을 전담하는 DMA와 2개의 버퍼를 교차 사용하는 핑퐁 버퍼 구조 도입.

결과: DMA가 백그라운드에서 새 프레임을 수신하는 동안, CPU는 이미 채워진 버퍼의 영상을 화면에 출력하도록 처리 순서를 분리하여 렌더링 대기 시간을 완전히 제거함.

  2. 운영체제 메모리 최적화를 통한 시스템 안정화

문제: 핑퐁 버퍼를 위해 2개의 영상 버퍼를 할당한 결과, RAM 사용량이 75.9%까지 급증하여 메모리 부족(Out of Memory) 위험 발생.

해결: 메모리 맵 구조 분석을 통해 동적 할당 비중이 낮음을 파악. OS의 예약 메모리 공간을 15KB에서 8KB로 축소 조정.

결과: RAM 점유율을 70.5%로 낮추고 시스템 구동 안정성을 성공적으로 확보함.

  3. 제어 패킷 경량화를 통한 통신 부하 최소화

문제: 화면 출력을 마친 후 모터 제어 보드로 무거운 영상 데이터를 그대로 넘길 경우 통신 부하가 큼.

해결: 전체 영상 데이터 대신, 비전 처리로 추출된 타겟의 '좌표'와 '인식 여부'만 담은 5Byte 크기의 경량화 패킷을 재설계하여 UART로 전송.

결과: 제어 통신 버스에 걸리는 부하를 대폭 감소시켜 실시간 모터 제어 응답성을 확보함.
